Sweep++

Turn a software-defined radio into a wideband spectrum analyser.

Download Stable v{{STABLE_VERSION}} Download Stable no release yet Download Nightly Nightly {{NIGHTLY_DATE}} · {{NIGHTLY_SHA}}

Free and open source, GPL-3.0. macOS 13.3+, Ubuntu 24.04+, Debian 13, Windows (experimental).

Features

See the whole band

Sweep a range far wider than the radio can see at once, stitched into one spectrum and waterfall.

Several ranges at once

Sweep separate ranges in one pass and skip the space between them, with 12 built-in presets.

Know what you're looking at

Band-plan labels, channel lists for Wi-Fi, cellular, LoRa/ISM, FPV and beacons, and your own channels.

Find signals

Markers with level readouts, automatic signal detection, and an activity history exported to CSV.

Record and replay

Every run is recorded. Save it as a .sweeps file and play it back in the History viewer.

Plugins

Radio drivers, FFT engines, band plans and channel lists are all plugins, and you can install more.

Works with HackRF One, HackRF Pro, bladeRF, RTL-SDR and Fobos SDR.

macOS

brew install aurimasniekis/sweeppp/sweeppp          # or aurimasniekis/sweeppp/sweeppp-nightly

Needs macOS 13.3 or newer, on Apple silicon or Intel.

Debian and Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL {{PAGES_URL}}/apt/sweeppp.gpg -o /etc/apt/keyrings/sweeppp.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/sweeppp.gpg] {{PAGES_URL}}/apt $(. /etc/os-release && echo "$VERSION_CODENAME") main nightly" | sudo tee /etc/apt/sources.list.d/sweeppp.list
sudo apt update
sudo apt install sweeppp          # or sweeppp-nightly

Works on Ubuntu 24.04, Ubuntu 26.04 and Debian 13; sweeppp-nightly installs beside sweeppp.

Windows builds, and archives for every platform, are on the releases page.
